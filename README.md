# SRK — мастерская металлоизделий

Адаптивный сайт-каталог для мастерской сварных изделий, прицепов, тележек, багажников для внедорожников, металлоконструкций и покраски.

## Текущая версия
- Одностраничный сайт без сборщика: `index.html`.
- Русский и казахский интерфейс с переключателем языка.
- Каталог с фильтрами по категориям.
- Адаптивная вёрстка для телефона и компьютера.
- Форма заявки в демонстрационном режиме. Она пока не отправляет данные на сервер.

## Перед публикацией для клиента
1. Уточнить официальное название мастерской и логотип.
2. Заменить демонстрационные фотографии на реальные фотографии изделий.
3. Добавить телефон, WhatsApp и адрес/город мастерской.
4. Подключить Supabase для хранения каталога и заявок, настроить безопасные политики доступа.
5. Подключить реальную отправку заявок и проверить весь путь заказа.
6. Согласовать цены, сроки, доставку и условия обработки персональных данных.

## Развёртывание
Статический сайт можно размещать на Vercel. После подключения репозитория изменения в production-ветке `main` будут запускать новое развёртывание.

## Важно
Текущая форма — макет интерфейса, не система приёма заказов. Не передавайте сайт клиенту как полностью рабочую систему заказа, пока не подключены и не проверены канал связи и база данных.
